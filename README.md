# 🚀 Postman API Collections

This repository contains Postman collections used for testing and validating API endpoints.  
It includes requests covering authentication, CRUD operations, and system workflows.

---

## 📂 Repository Structure



- **`api-collection.json`** → Exported Postman collection with grouped requests for easier testing and reuse.

---

## 🛠️ How to Use
1. Download the collection file from this repo.  
2. Open **Postman** → click **Import**.  
3. Choose the JSON file.  
4. Run requests directly or integrate with **Newman** for automated testing.

---

## ✅ Highlights
- API testing with **Postman**
- Organized collections for efficient request management
- Support for authentication and data-driven requests
- Ready to use with **Newman** for CI/CD pipelines

---

## 🔗 Tools
- [Postman](https://www.postman.com/) – API client for building and testing APIs  
- [Newman](https://www.npmjs.com/package/newman) – CLI tool for running Postman collections
